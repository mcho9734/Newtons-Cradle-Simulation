# Newton's Cradle Simulation
A physics simulation of Newton's Cradle using the pandas and vpython libraries. The pandas library is used to read CSV files containing the cradle's
data and convert them to objects of type PendulumEntry, which describes each individual pendulum in the cradle. The type PendulumEntry is defined in pendulum.py file
in the support file.<br><br>
The vpython library is used to perform the physics calculations of the simulation.

### Features
The special_cradles.py file contains properties of the cradle that can be changed, such as mass, coefficient of restitution, and color.<br>

Code scaffolding is from the CS1a course at Caltech. Main logic for functions coded by self.
